# 웹 서버(Web Server) - 웹 클라이언트(Web Client)

- **프론트엔드 (Front-end):** 서비스 요청 받는 부분
- **백엔드 (Back-end):** 서비스 요청을 처리하는 부분
- **웹 리소스 (Web Resource):** 나타내지는 부분

## 웹 구성 요소
- **Hyper Text Markup Language (HTML):** 구조
- **Cascading Style Sheets (CSS):** 표현
- **JavaScript (JS):** 동작
